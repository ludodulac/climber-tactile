CLIMBER LCDASCENSION · 1986 REVISITÉ

GRIMPE ! Casse les briques en 2 sauts · traverse un trou, puis déplace-toi en l'air pour atterrir sur le plateau supérieur.

Comment jouer · règles et sources

Déplace-toi de gauche à droite, saute pour gravir 25 étages par phase. Frappe deux fois les briques au-dessus de toi pour les ouvrir. Les Blockmen peuvent réparer les trous ; évite-les, ainsi que les oiseaux et les épines. Après chaque phase, essaie d'attraper Hentori en deux sauts ; toutes les cinq phases, affronte le dragon Dragalo avec l'épée. Trois erreurs terminent la partie, avec reprise sept étages plus bas.

Les sprites sont des dessins originaux en positions fixes pour retrouver la sensation LCD. Le jeu est une récréation indépendante : ce n'est ni une ROM Nintendo, ni une émulation exacte ; le rythme, le score et certains comportements sont adaptés faute de documentation complète.

Une création indépendante inspirée du Climber Crystal Screen. Aucune image ni ROM Nintendo utilisée.
